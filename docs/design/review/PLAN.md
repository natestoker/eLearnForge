# Redesign plan (from Claude Design's review, Nov 2026)

`REVIEW.txt` is the text of the review. The order below is the review's own.

| Phase | What | Status |
| --- | --- | --- |
| 1 | **Tokens** in `src/styles.css`: type (6 steps, 11px minimum), radius (3 + pill), spacing, z layers, shadows, `--border-strong`, status colors. Chrome rules moved onto them (145 font sizes, 110 radii). Publish and Triggers moved from blue-grey onto the root neutrals. Input outlines on `--border-strong`. | Done (v6.22, v6.28 to v6.30): tokens, chrome on type, radius and spacing tokens, overlays on the named z layers, course colours in their own `--c-*` set, a test that fails on literal font sizes, radii and overlay z-index. Small z-index numbers that only order things inside the canvas, timeline or player stay literal. The `--c-*` set lives in `:root` (not on the slide root) so lightbox and preview slides get it too. |
| 2 | **One dialog shell**; Player Settings, Resources, Glossary and Banks become sections of a single Course settings dialog (with Accent, Brand colours, default transition, a live player preview, real empty states). Pen tool, Welcome, Story view and Publish on the same shell. | Done (v6.23, v6.29, v6.30): Course settings dialog; Pen tool and Welcome on the shared frame; Story view as a wrapping grid. Publish keeps its own frame (same tokens). |
| 3 | **Ribbon holds commands, forms move to the inspector.** Seven tabs become four (Insert, Arrange, Animate, View) on a 96px shelf with a More menu; Slide settings become the inspector's empty state; Triggers and Variables become right-panel tabs with count badges; animation timing edited in one place. | Done (v6.24, v6.28, v6.29), including the More menu, the block context menu and folding inspector sections. |
| 4 | **Phone player**: reflow to one column under 600px (16px text, 44px targets), fit view with a rotate hint for position-dependent slides, per-slide Auto / Reflow / Fit, tap-to-place drag and drop, Phone preview, a publish check. | Done (v6.25, v6.29): reflow, fit view, per-slide override, tap-to-place, Phone preview, publish check, top bar, landscape rail, Continue merged into Next, entrances that play as blocks scroll into view (v6.30). |
| 5 | **Everything else**: quiz feedback with an icon and a word; a real end-of-course state; undo toast for deletes; one Menu primitive; one save indicator; zoom into the status bar; collapsing Layers; timeline at 24px rows; variables with friendly names; typed glyphs replaced by Lucide; Publish loose ends. | Five batches done (v6.26 to v6.30). Decided against moving Tracking to Publish's right column (it unbalances the dialog). |

Phases 2 to 4 each change how the editor is organised, so each should land on its own and be looked at before the next.
