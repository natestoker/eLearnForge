 2 · Modal.tsx · GlobalSettings.tsx · BanksEditor.tsx · PublishDialog.tsx
 One dialog pattern
 Player Settings, Resources, Glossary and Banks become sections of one Course settings dialog, opened from a Course button in the top bar. It also takes Accent, Brand colours and the default transition from the Home tab, which removes the duplicate "Player accent" field. Publish keeps its layout and moves onto the same shell and neutrals.
 Shell 
Widths 480 / 720 / 980. Radius 12. Header 64px with 18px title, 13px context line and a 28px Lucide close button. Body padding 24. Footer 64px on --bg .
 Body 
Sections under 11px mono labels. Related rows share one --panel-2 card. Every control has a visible label. Body scrolls; header and footer stay put.
 Footer 
Status on the left, actions on the right, primary last. Settings apply live, so the footer has one Done button and says how to undo.
 Empty state 
Icon, what the thing is for in one sentence, primary action, one shortcut action, and a ghosted example of what the learner will see.

 4 · runtime/Player.tsx · runtime/PlayerChrome.tsx · blocks/*/Runtime.tsx
 Phone player: reflow by default, fit view as the fallback
 Below 600px wide in portrait, the player stops scaling the 1280px stage. It renders the slide's blocks as one scrolling column, in the reading order the slide already has for screen readers, at real text sizes (16px body, 44px targets). Each block's Runtime renders at container width. Decorative shapes are dropped. Slides whose meaning depends on position (hotspots, labelled graphics, motion paths, overlapping blocks) keep the 16:9 stage with pinch-zoom and a rotate hint. The published file stays one HTML file with system fonts.
