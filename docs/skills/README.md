# Skills

Reference notes for working on this project with Claude, in skill form. Each
folder is one skill; `SKILL.md` is the entry point.

| Skill | Covers |
| --- | --- |
| `elearnforge` | Architecture, conventions and tests for this codebase |
| `story-file-internals` | Reading and editing a Storyline `.story` file |
| `story-file-writing` | Building a `.story` file from scratch, with a checker script |

To install or update one in Claude, zip its folder (the folder itself at the
top level of the zip) and upload it under Settings > Capabilities > Skills.
